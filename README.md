## Requirements:
- Python: 3.12.x 
- Python libraries: 
    - pillow [required for the photo widget]
    - winsdk [required for the media widget] 

## How to run:
1. Clone this repository to your local machine: ```git clone https://github.com/tiinaao/PC-Widgets.git```
2. Navigate to the project directory: ```cd PC-Widgets/general```
3. Install required dependencies (if you haven’t already): ```py -m pip install -r requirements.txt```
4. Run the powershell script: ```powershell -File run.ps1```
<br>*(If the script is blocked by execution policy restrictions, run the following command instead: ```powershell -ExecutionPolicy Bypass -File run.ps1```)*
5. Once the application starts, you may close the command prompt.
6. Enjoy!!

## Shortcuts:
- Alt - Move the widget
- Shift - Resize the widget
- Space - Open widget settings
- Right Click - Close the widget
